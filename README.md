# 오토워커 Q&A 정리

**오토워커 2기 사담방**(카카오톡 오픈채팅)에 올라온 질의응답과 용어를 정리한 단일 페이지 사이트입니다.

🔗 **사이트**: https://danielall-wj.github.io/autoworker02/

## 구성

- `index.html` — 사이트 전체(HTML/CSS/JS가 한 파일에 들어있는 정적 페이지). 별도 빌드 과정이 없어 이 파일만 고치면 바로 배포됩니다.
  - `DATA` 배열 — Q&A 항목. `major`(대분류) · `sub`(하위 카테고리) · `date`(`"8/12"` 또는 `"8/13 15:34"`처럼 날짜만/날짜+시간) · `q` · `a`로 구성됩니다.
  - `GLOSSARY` 배열 — 용어 설명. `major` · `id`(고유값, 중복 금지) · `term` · `aliases`(본문에서 자동으로 링크될 표기들) · `desc`로 구성됩니다.
  - `LAST_UPDATED` / `LAST_UPDATED_NOTE` — 카카오톡 원문을 어디까지 확인해서 반영했는지 기록. 하단 footer에 표시됩니다.
- `README.md` / `README.html` — 이 문서(마크다운/HTML 버전).

## 자동 계산되는 값

헤더의 `REFERENCE` 날짜 범위와 "분류 비중" 통계(총 건수, 카테고리별 막대·개수)는 `DATA` 배열을 기준으로 로드 시점에 자동 계산됩니다. 항목을 추가·삭제해도 손으로 숫자를 맞출 필요가 없습니다.

## 내용 업데이트 방법

1. 카카오톡 사담방 원문에서 조교 답변이 붙은 Q&A를 찾아 `DATA`에 항목을 추가합니다. 새로 추가하는 항목은 원문의 정확한 시:분을 알 수 있으면 `date`에 함께 적어주세요(예: `"8/17 13:13"`). 시각을 확인할 수 없으면 날짜만 적습니다(예: `"8/12"`).
2. 새로운 개념·용어가 나오면 `GLOSSARY`에 추가합니다. `id`는 기존 값과 겹치지 않게 지어주세요.
3. 다 반영했다면 `LAST_UPDATED` / `LAST_UPDATED_NOTE`를 원문을 확인한 시점 기준으로 갱신합니다.
4. 커밋 전에 `index.html`을 브라우저로 열어(또는 `python3 -c "..."`로 `DATA`/`GLOSSARY` 배열만 `eval`해서) 문법 오류와 통계가 정상인지 확인하는 걸 권장합니다.

## 협업 시 주의

이 저장소는 여러 세션/작업자가 같은 `index.html`을 동시에 고칠 수 있습니다. 푸시 전에 `git fetch`로 원격에 새 커밋이 없는지 확인하고, 있다면 겹치는 Q&A 항목이 없는지 살펴본 뒤 병합하세요.
